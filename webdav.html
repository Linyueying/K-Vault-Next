测试连接

填入账号密码，验证服务端是否可达。

挂载步骤

  1. 此电脑 → 映射网络驱动器。
  2. 地址填 \\host@SSL\dav，勾选「使用其他凭据」。
  3. 输入用户名与密码。
net use Z: \\host@SSL\dav /user:用户名 密码
  1. Finder 按 ⌘K，打开「连接服务器」。
  2. 地址填 https://host/dav。
  3. 选择「注册用户」，输入用户名与密码。
  1. 安装支持 WebDAV 的文件管理器：Documents、Solid Explorer、Material Files 等。
  2. 新建连接 → 选 WebDAV → 填入上方地址与账号。
  1. 列目录：
curl -u 用户名:密码 -X PROPFIND https://host/dav/ -H "Depth: 1"

rclone：rclone config → 选 webdav → URL 填服务地址。

测试 Token

填入 API Token，验证能否列出工具。

客户端配置

claude mcp add --transport http kvault __BASE__/mcp --header "Authorization: Bearer kvault_xxx"

写入 ~/.cursor/mcp.json：

{
  "mcpServers": {
    "kvault": {
      "url": "__BASE__/mcp",
      "headers": {
        "Authorization": "Bearer kvault_xxx"
      }
    }
  }
}

写入 ~/.codex/config.toml：

[mcp_servers.kvault]
url = "__BASE__/mcp"
bearer_token_env_var = "KVAULT_API_TOKEN"
curl -s __BASE__/mcp \
  -H "Authorization: Bearer $KVAULT_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
