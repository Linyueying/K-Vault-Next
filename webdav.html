挂载指引

按平台选择对应步骤。点击标题展开。

Windows 资源管理器
  1. 打开「此电脑」，点击顶部「映射网络驱动器」。
  2. 文件夹填入：\\host@SSL\dav（注意用 @SSL 走 HTTPS）。
  3. 勾选「使用其他凭据连接」，输入本站用户名密码。
  4. 若提示证书问题，选择继续即可（自签证书场景）。

命令行方式：net use Z: \\host@SSL\dav /user:用户名 密码

macOS Finder
  1. Finder 菜单：前往 → 连接服务器（⌘K）。
  2. 服务器地址填入：https://host/dav。
  3. 选择「注册用户」，输入用户名密码，即可在 Finder 中看到为共享磁盘。
手机 App（iOS / Android）
  1. 安装任一支持 WebDAV 的文件管理器：Documents（iOS）、Solid Explorer / Material Files（Android）、RaiDrive（全平台）。
  2. 新增连接 → 选择 WebDAV → 填入上面的服务地址。
  3. 输入用户名密码即可浏览、上传、下载。
命令行（curl / rclone）

列目录：

curl -u 用户名:密码 -X PROPFIND https://host/dav/ -H "Depth: 1"

上传：

curl -u 用户名:密码 -T ./local.txt https://host/dav/local.txt

rclone：rclone config → 选 webdav → URL 填服务地址。
