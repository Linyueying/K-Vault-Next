01 · One file layer

三种方式，同一个文件中枢。

不为文件创造新的孤岛。桌面、AI 与 Web 各取所需，背后始终是同一份数据、同一套权限。

像本地磁盘一样自然

挂载到 Finder、资源管理器或手机 App。拖拽上传、断点续传，不必再打开网页。
