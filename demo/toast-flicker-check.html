低性能设备上 Toast 闪烁 · 修复前后对照

两侧渲染的是同一个 toast（已切换至：智能），唯一区别是动画实现。
建议配合 Chrome DevTools 的 Performance → CPU 4x/6x 降速 观察： 左侧会出现「淡入 → 被打回起点 → 再淡入」的往复（闪烁），右侧平滑到位。

修复前 双套动画竞争

元素上同时存在 animation: toastIn 与 Vue 的 .toast-enter-from 过渡。 两者争夺同一个 transform / opacity，掉帧时阶段错开 → 闪烁。

修复后 单套过渡 + 独立合成层

入场只由 Vue 过渡驱动，起点/缓动/时长与原来完全一致（观感不变）； 并提前 translateZ(0) 提层，避免每帧重新 raster。
